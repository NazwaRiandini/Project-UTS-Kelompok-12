# Nazwa Azzahra Riandini — Portfolio

A recruiter-focused single-page portfolio website for Nazwa Azzahra Riandini, an Informatics student and aspiring web developer.

The current feature branch also includes a persistent dark/light mode toggle, a Project Team - Kelompok 12 section for Nazwa Riandini and Ihsan, and a link to the team's GitHub repository.

## Contents

- `index.html` — page structure and resume-based content
- `styles.css` — responsive visual styling
- `script.js` — mobile navigation and footer year

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.
